Vice Cover Studio — an offline web app that turns your photos and a caption into GTA 6-style cover art, exported as PNG in 1080x1080, 1080x1350 and 1920x1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To hand the app in as the entry does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
